# IT Help Desk Home Lab

## About This Project

This repository documents my hands-on practice in IT support, desktop troubleshooting, and system administration.

The goal of this lab is to develop practical technical skills relevant to entry-level IT support and help desk positions through simulated workplace scenarios.

## Lab Environment

- Host machine: MacBook Pro (Apple Silicon M5)
- Virtualization software: UTM
- Guest operating system: Windows 11 ARM64
- Environment: Local virtual machine

## Projects

### Project 1: Windows 11 Troubleshooting

Practical exercises involving common desktop support incidents.

Topics include:
- Windows performance troubleshooting
- Network connectivity
- Software installation and troubleshooting
- Local user account management
- Printer troubleshooting

**Status:** In progress

### Project 2: Active Directory and User Management

Planned exercises involving:
- User and group administration
- Password resets and account management
- Permissions
- Group Policy
- Domain joining

**Status:** Planned

### Project 3: IT Service Desk Simulation

Planned exercises involving:
- Incident management
- Ticket prioritization
- Troubleshooting documentation
- Escalation procedures
- Knowledge base articles

**Status:** Planned

## Documentation

Each completed exercise will include:
- The reported issue
- Troubleshooting steps
- Findings and root cause
- Resolution
- Verification
- Supporting screenshots

## Learning Objectives

Develop practical experience with Windows administration, desktop support, troubleshooting methodology, technical documentation, and customer-focused IT support.
